# Scope-to-Profit

Workspace de exploración para un SaaS que transforma conversaciones con clientes en specs, presupuestos rentables y control de cambios de alcance.

## Documento base

- `docs/scope-to-profit.pdf` — visión del producto, MVP, marketing y plan inicial.
- `docs/scope-to-profit.txt` — fuente editable del PDF.

## Próximo objetivo

Validar el flujo con proyectos reales de freelancers y agencias pequeñas antes de construir el MVP completo.
