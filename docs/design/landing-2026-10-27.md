# Shorter ScopeProfit landing

## Argument and inventory

The page explains one transition: a client's request becomes a scope document, through tools in an AI agent. It is not a hosted chat or dashboard. The existing long home mixed product explanation with installation snippets and the entire tool catalogue. Installation belongs in the existing MCP guide; the tool finder remains in a closed native disclosure.

Assets: original supplied logo and symbol, the real PDF from the fictional Agencia Horizonte ChatGPT test, existing repository documentation and tool catalogue. No customer claims, stock photography, testimonials, prices or invented interface.

Copy deck: "Del pedido al alcance." -> request versus clarified scope -> real document pages -> self-hosted MCP explanation -> installation. The excerpt compresses the fictional conversation, not the final document verbatim. The pending question illustrates the clarification stage; the final PDF records its answer.

## Direction

Type-only editorial statement. Original red/black identity and original wordmark retained. Boska body of display lettering contrasts the document's factual sans-serif text. Two-line statement hero. Call-and-response scope section, then compact connection section. Four real PDF pages carry the visual proof.

A cropped single-word hero was rejected because it hid the meaning the user asked to clarify. The duration bar was replaced with call-and-response because no measured durations exist. Atmospheric photographs were omitted: they would misrepresent the product and make the page longer. The CTA and footer are compact rather than full-screen for the same reason. One reduced-motion-aware reveal system and a small footer wordmark scale replace ornamental effects.
